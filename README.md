# The Grocery Report

Prototipo de una app B2C que lee los tickets del supermercado (Gmail o foto) y ayuda a los hogares a gastar menos en la compra: avisos de subidas de precio, comparador entre supermercados, presupuesto semanal y lista de la compra.

## Qué hay en este repositorio

| Carpeta | Contenido |
|---|---|
| `index.html` | Portada para inversores con enlaces a todo |
| `web.html` | Página web del producto |
| `grocery-report-app-movil.html` | Prototipo de la app móvil |
| `app.html` | Prototipo de la app para ordenador |
| `grocery-report-funnel.xlsx` | Modelo de ventas (funnel 2027) en Excel |

Todo son páginas HTML estáticas: no necesitan servidor ni instalación.

## Publicarlo con GitHub Pages

1. Sube el contenido de esta carpeta a la raíz de un repositorio público.
2. En el repositorio: **Settings → Pages**.
3. En **Build and deployment**, elige **Deploy from a branch**, rama `main` y carpeta `/ (root)`. Guarda.
4. En uno o dos minutos la web estará en `https://<tu-usuario>.github.io/<nombre-del-repo>/`.

## Aviso

Los datos, tickets y precios que aparecen son de ejemplo. No son datos de clientes ni precios reales de ningún supermercado. Los precios de la suscripción son provisionales.
